# Product Strategy & Scope

## Purpose

Turn research into a coherent product strategy and phased roadmap.

## Define

- Product vision
- Target users
- Positioning
- Core value proposition
- User-selling points
- Unique selling points
- Differentiators
- Primary user journeys
- Core feature set
- Monetization/business model when relevant
- Success metrics
- Future vision

## Feature Standard

For each important feature define:

1. What it does
2. Who benefits
3. What problem it solves
4. Why it matters
5. How it compares with existing solutions
6. Dependencies
7. Security/privacy implications
8. Testing needs
9. Performance implications
10. Version target

## Scope Classes

Every proposed item belongs to one class:

- Required — necessary for the approved version
- Important — valuable but not a blocker
- Nice-to-have — useful polish
- Future — deliberately deferred
- Rejected — considered and intentionally excluded

Never silently promote future work into the current version.

## Roadmap

Break the approved product into coherent phases such as V1, V2, V3, and later work. Each version must have a clear objective, included work, excluded work, completion criteria, and release gate.

## Product Reality Check

At every milestone ask whether the latest work makes the product more useful, understandable, trustworthy, or differentiated. Remove or defer feature bloat that does not contribute meaningful value.
