# Performance, Resource & Cost Optimization

## Purpose

Keep the product responsive, efficient, scalable, and financially sensible without damaging maintainability or UX.

## Consider

CPU, memory, disk, network, startup time, rendering, bundle size, database efficiency, queries, API latency, caching, concurrency, background work, storage, build time, and infrastructure cost.

## Web Products

Consider page performance, critical rendering paths, JavaScript weight, image/media optimization, caching, API efficiency, database behavior, responsiveness, interaction latency, and perceived performance.

## Continuous Optimization

Profile before making major performance claims where practical. Fix measured bottlenecks and avoid premature micro-optimization.

## Resource Research

When appropriate, research StudentOffers.co, GitHub Student benefits, educational plans, free tiers, credits, open-source tools, and discounted services. Compare them on capability, limits, reliability, privacy, security, lock-in, production suitability, and future cost.

Never make a technical decision solely because a service is free.

## Quality Balance

Optimize across performance, cost, reliability, security, developer experience, and user experience. The fastest implementation is not useful if it makes the product fragile or unpleasant.
