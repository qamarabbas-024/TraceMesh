# AI / Developer Handoff

## Purpose

Provide a compact transfer point between Gemini, Claude, ChatGPT, another AI agent, or a human developer.

## Include

- What the project is
- Why it exists
- Current product vision
- Current quality target
- Current architecture
- Current version/phase
- Key decisions
- Important constraints
- Known bugs/issues
- Security risks
- Performance concerns
- Current blockers
- What must not be changed casually
- Next approved steps

## Handoff Rule

Write only verified and useful context. Do not turn this into a second complete project documentation system. Link or point to the authoritative project documents when more detail is needed.

## Continuation Rule

A new agent should read `.project-ai/00_CORE.md`, the relevant specialist files, and the current project state before acting. It should inspect the actual repository before trusting historical assumptions.
