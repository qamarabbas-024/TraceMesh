# Live Project State

## Purpose

Maintain a compact operational checkpoint that lets an AI or human resume work without reconstructing the entire project.

## Keep Updated

- Project name
- Project type
- Quality target
- Current version/phase
- Overall status
- Completed work
- Current work
- Next approved work
- Deferred work
- Known bugs
- Known risks
- Security status
- Test status
- Architecture status
- Performance status
- Documentation status
- Current branch
- Last verified commit
- Last verified remote state
- Blockers

## Status Vocabulary

Use clear states such as Planned, In Progress, Verified, Blocked, Deferred, Released, or Rejected.

## Rule

Update this file after significant phase completion, release gates, major decisions, blockers, and successful recovery from failures.
