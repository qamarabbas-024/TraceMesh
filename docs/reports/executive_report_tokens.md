# Executive PDF Report Layout Tokens

## Typography & Color Hierarchy
- **Header Accent**: `#00F5FF` (TraceMesh Cyan)
- **Warning / Threat Accent**: `#FF3366` (Threat Alert Red)
- **Body Font**: Inter / Roboto Sans-Serif
- **Monospace Code**: JetBrains Mono / Fira Code

## Output Specs
- Format: ISO A4 / US Letter
- Resolution: 300 DPI vector rendering
- Metadata: Signed cryptographic SHA-256 dossier hash embedded in footer
