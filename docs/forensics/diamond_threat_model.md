# Diamond Threat Model Attribution Framework

## Core Vertices
1. **Adversary**: APT entity, operator persona, sponsor state/group.
2. **Capability**: Exploits, malware frameworks, tooling, obfuscation kits.
3. **Infrastructure**: C2 servers, botnets, DNS fast-flux relays, bulletproof hosting.
4. **Victim**: Target sector, geography, system vulnerabilities.

## Meta-Features
- Confidence level: Low (0-30%), Medium (31-70%), High (71-100%).
- Kill Chain Phase: Reconnaissance, Weaponization, Delivery, Exploitation, C2, Actions on Objectives.
